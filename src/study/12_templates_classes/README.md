### 1. 模板类

| 场景     | 推荐方法             | 优点       | 缺点         |
|--------|------------------|----------|------------|
| 小型模板类  | 全部代码放头文件         | 简单，无链接问题 | 头文件较长      |
| 中大型项目  | 拆分为`.h` + `.inl` | 代码整洁，易维护 | 需管理多个文件    |
| 明确已知类型 | 显式实例化在`.cpp`     | 减少编译时间   | 需手动维护实例化列表 |

### 2. 模板非类型参数

| **类别**     | **说明**                                            | **示例**                                                                                     | **注意事项**                                                               |
|------------|---------------------------------------------------|--------------------------------------------------------------------------------------------|------------------------------------------------------------------------|
| **定义**     | 模板参数中传递**具体的值**（非类型），值必须是编译期常量（`constexpr`）。      | `template <typename T, int size>`                                                          | 必须明确值的类型（如`int`），且值在编译时确定。                                             |
| **允许的类型**  | 整型、枚举、指针/引用、函数指针、`std::nullptr_t`、浮点型（C++20起）。    | `int`, `enum Color`, `int*`, `void (*func)()`, `float`                                     | 浮点型仅C++20及以上支持。                                                        |
| **核心用途**   | 在编译期确定参数，生成更高效或灵活的代码。                             | 静态数组大小、策略标志、编译期计算。                                                                         | 常用于容器类（如`std::array`）。                                                 |
| **示例代码**   | 静态数组模板类：类型参数控制元素类型，非类型参数控制大小。                     | ```cpp<br>StaticArray<int, 12> arr;<br>arr[0] = 5;```                                      | 数组大小在编译期确定，栈上分配，无需动态内存。                                                |
| **限制**     | 1. 值必须是`constexpr`。<br>2. 类型严格匹配。<br>3. 不支持运行时变量。 | ```cpp<br>int x = 5;<br>StaticArray<int, x> arr; // 错误！x非constexpr```                      | 使用`constexpr`修饰变量：<br>`constexpr int x = 5;`                           |
| **类外成员函数** | 在类外定义成员函数时需携带模板声明和作用域限定。                          | ```cpp<br>template <typename T, int size><br>T* StaticArray<T,size>::getArray() { ... }``` | 必须完整声明模板参数（`T, size`）和类作用域（`StaticArray<T, size>`）。                    |
| **实际应用**   | 标准库中的`std::array`使用非类型参数指定大小。                     | ```cpp<br>#include <array><br>std::array<int, 5> arr;```                                   | 替代C风格数组，提供迭代器、边界检查等特性，性能与C数组相同。                                        |
| **错误场景**   | 尝试用非`constexpr`值实例化模板。                            | ```cpp<br>int x{4};<br>Foo<x> f; // 错误！```                                                 | 编译报错：`error: non-type template argument is not a constant expression`。 |
| **优势**     | 1. 编译期优化，无运行时开销。<br>2. 类型安全，避免动态内存问题。             | 静态数组无需`new/delete`，避免内存泄漏。                                                                 | 适合嵌入式开发或高性能场景。                                                         |

### 3. 函数模板特化

- **非模板函数**：灵活、简单，优先用于重载。优先于模板函数和模板特化
- **模板特化**：
- 完全特化需严格匹配签名，适合需要精准控制的场景。
- 类成员函数特化需特化整个类模板。
- **实际应用**：
- 标准库中`std::vector<bool>`是类模板特化的经典案例，优化布尔值的存储。

通过合理选择非模板函数或模板特化，可以在保持代码泛用性的同时，为特定类型提供高效定制实现。

### 4. 类模板特化

| **场景**     | **示例**                             |
|------------|------------------------------------|
| **优化存储**   | `Storage8<bool>`用1字节代替8字节。         |
| **定制行为**   | `Storage<double>::print()`输出科学计数法。 |
| **兼容特殊类型** | 为指针类型提供特化（如`Storage<T*>`管理指针生命周期）。 |
