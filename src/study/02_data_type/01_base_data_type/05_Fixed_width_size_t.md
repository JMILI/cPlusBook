### 固定宽度整数与`std::size_t`总结

#### 固定宽度整数介绍
- **背景**：C++仅保证整数类型的最小大小，具体大小取决于系统。这可能导致程序在不同平台上表现不一致。
- **解决方案**：C99引入了固定宽度整数类型（通过`<cstdint>`头文件），这些类型在任何架构上都有确定的大小。

| 类型          | 描述             | 范围                         |
|---------------|------------------|------------------------------|
| `std::int8_t` | 一字节有符号     | -128 到 127                  |
| `std::uint8_t`| 一字节无符号     | 0 到 255                     |
| `std::int16_t`| 两字节有符号     | -32,768 到 32,767            |
| `std::uint16_t`| 两字节无符号    | 0 到 65,535                  |
| `std::int32_t`| 四字节有符号     | -2,147,483,648 到 2,147,483,647 |
| `std::uint32_t`| 四字节无符号    | 0 到 4,294,967,295           |
| `std::int64_t`| 八字节有符号     | -9,223,372,036,854,775,808 到 9,223,372,036,854,775,807 |
| `std::uint64_t`| 八字节无符号    | 0 到 18,446,744,073,709,551,615 |

**示例代码**：
```cpp
#include <cstdint> // 引入固定宽度整数
#include <iostream>

int main() {
    std::int16_t i{5};
    std::cout << i << '\n';
    return 0;
}
```

#### 快速与至小整数
- **快速类型**：提供最快的整数类型，至少为指定的位数。
- **至小类型**：提供最小的整数类型，至少为指定的位数。

**示例代码**：
```cpp
#include <cstdint>
#include <iostream>

int main() {
    std::cout << "least 8:  " << sizeof(std::int_least8_t) * 8 << " bits\n";
    std::cout << "fast 16: " << sizeof(std::int_fast16_t) * 8 << " bits\n";
    return 0;
}
```

#### `std::size_t`
- **定义**：`std::size_t`是一个无符号整数类型，通常用于表示对象的大小或长度。
- **用途**：`sizeof`操作符返回`std::size_t`类型的值。

**示例代码**：
```cpp
#include <cstddef> // 引入 std::size_t
#include <iostream>

int main() {
    std::cout << sizeof(std::size_t) << '\n'; // 打印 size_t 的大小（以字节为单位）
    return 0;
}
```

#### 最佳实践
1. **优先选择固定宽度整数**：当需要特定范围的整数值时，使用固定宽度整数类型（如`std::int32_t`）。
2. **避免8位固定宽度整数**：由于可能被视为字符类型，推荐使用16位类型（如`std::int16_t`）。
3. **谨慎使用快速/至小类型**：它们的实际大小可能会导致不可预测的行为，尤其是在不同的架构上。
4. **使用`std::size_t`处理大小相关的问题**：例如数组索引、内存分配等场景。

#### 注意事项
- **性能考虑**：虽然快速类型可能在某些架构上提供更好的性能，但这也可能导致内存浪费。
- **兼容性问题**：在不同系统上测试您的程序以确保其行为符合预期非常重要。
- **编译器特定类型**：避免使用编译器特定的固定宽度整数类型（如Visual Studio中的`__int8`），而应坚持标准类型。
