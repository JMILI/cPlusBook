### 有符号整数总结

#### 定义与表示
- 在C++中，默认情况下整数类型是有符号的，能够表示正数、负数以及零。
- 使用单个比特（称为符号位）来表示数字的符号，剩余比特表示数值大小。

#### 基本类型及其大小
| 类型        | 最小大小(字节) | 备注                     |
|-------------|----------------|--------------------------|
| `short`     | 2              | 简洁形式优于`short int`   |
| `int`       | 2              | 现代机器上通常是4字节    |
| `long`      | 4              | 简洁形式优于`long int`    |
| `long long` | 8              | 简洁形式优于`long long int` |

注意：C++只保证这些类型的最小大小，具体大小可能因编译器和平台而异。可以通过`sizeof`运算符查询实际大小。

#### 取值范围
| 类型大小 | 取值范围                           |
|----------|------------------------------------|
| 8位      | -128 到 127                        |
| 16位     | -32,768 到 32,767                  |
| 32位     | -2,147,483,648 到 2,147,483,647    |
| 64位     | -9,223,372,036,854,775,808 到 9,223,372,036,854,775,807 |

#### 溢出
尝试将超出变量范围的值赋给有符号整数会导致未定义行为（例如，将140赋给8位有符号整数）。应避免这种情况，必要时选择更大的数据类型。

#### 整数除法示例
```cpp
#include <iostream>

int main() {
    std::cout << "20 / 4 = " << 20 / 4 << '\n'; // 输出: 5
    std::cout << "8 / 5 = " << 8 / 5 << '\n';   // 输出: 1 (注意丢失的小数部分)
    return 0;
}
```
整数除法会截断小数部分，不会进行四舍五入。

#### 最佳实践
- 避免使用“int”后缀，直接使用简短形式如`short`代替`short int`。
- 默认情况下整数是有符号的，因此不需要显式地指定`signed`关键字。
- 当预期结果可能超过当前类型范围时，考虑使用更大范围的数据类型以防止溢出。
