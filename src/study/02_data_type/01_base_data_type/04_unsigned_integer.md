### 无符号整数总结

#### 定义与表示
- **定义**：无符号整数是只能保存非负整数值（包括0）的数据类型。
- **定义方式**：在C++中，使用`unsigned`关键字定义无符号整数。

```cpp
unsigned short us;    // 无符号短整型
unsigned int ui;      // 无符号整型
unsigned long ul;     // 无符号长整型
unsigned long long ull; // 无符号长长整型
```

#### 取值范围
| 类型大小 | 取值范围                         |
|----------|----------------------------------|
| 8位      | 0 到 255                         |
| 16位     | 0 到 65,535                      |
| 32位     | 0 到 4,294,967,295               |
| 64位     | 0 到 18,446,744,073,709,551,615  |

n位无符号变量的范围为0到\(2^n - 1\)。

#### 溢出行为
尝试将超出无符号整数范围的值赋给它会导致环绕行为（模运算）。例如，将280赋给一个8位无符号整数会得到24（因为280 % 256 = 24）。

```cpp
#include <iostream>

int main() {
    unsigned short x{65535}; // 最大的16位无符号整数
    std::cout << "x was: " << x << '\n'; // 输出: 65535
    x = 65536; // 环绕回0
    std::cout << "x is now: " << x << '\n'; // 输出: 0
    return 0;
}
```

#### 使用无符号整数的潜在问题
1. **意外溢出**：
   ```cpp
   unsigned int x{2}, y{3};
   std::cout << x - y << '\n'; // 预期输出 -1，实际输出 4294967295
   ```
2. **混合有符号和无符号操作时的行为**：
   ```cpp
   signed int s{-1};
   unsigned int u{1};
   if (s < u) std::cout << "-1 is less than 1\n"; 
   else std::cout << "1 is less than -1\n"; // 实际输出 "1 is less than -1"
   ```

#### 最佳实践
- **避免使用无符号类型**，除非特定情况下确实需要（如位操作或处理数组索引），以减少溢出和其他逻辑错误的风险。
- 对于计数物品的数量等场景，即使这些数量应为非负，也推荐使用有符号整数。

#### 特殊情况下的使用
- 在进行位操作或需要利用环绕行为的算法（如加密）时，无符号整数可能是更好的选择。
- 在嵌入式系统开发中，出于性能考虑，也可能需要使用无符号整数。
