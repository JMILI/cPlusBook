## **值类别（左值 lvalue 和右值 rvalue）**

在 C++ 中，表达式的计算不仅仅是得到一个值。它还有两个重要的属性：**类型** 和 **值类别**。为了理解 C++ 的表达式如何工作，我们首先需要了解左值（lvalue）和右值（rvalue）这两个概念。

### **表达式简介**
在 C++ 中，表达式是可以执行以产生特定值的字面值、变量、运算符和函数调用的组合。例如：

```cpp
#include <iostream>

int main() {
    std::cout << 2 + 3 << '\n';  // 表达式 2 + 3 产出值 5
    return 0;
}
```

在这个例子中，`2 + 3` 是一个表达式，计算结果为 `5`，并将其输出。这是一个简单的值计算过程。

### **表达式的副作用**

有时，表达式不仅会产生一个值，还会带来副作用，即对程序状态的改变。例如：

```cpp
#include <iostream>

int main() {
    int x { 5 };
    ++x;  // 这个表达式的副作用是将 x 加 1
    std::cout << x << '\n';  // 打印 6
    return 0;
}
```

在这个程序中，`++x` 表达式不仅计算了一个值，它还修改了 `x` 的值。这种修改就是副作用。

### **表达式的属性：类型与值类别**

C++ 中的所有表达式都有两个属性：**类型** 和 **值类别**。

#### 1. **表达式的类型**

表达式的类型是由其计算出来的值的类型决定的。例如：

```cpp
int main() {
    auto v1 { 12 / 4 };   // int / int => int
    auto v2 { 12.0 / 4 }; // double / int => double
    return 0;
}
```

在这段代码中：
- `v1` 的类型是 `int`，因为 `12 / 4` 计算结果是整数。
- `v2` 的类型是 `double`，因为 `12.0 / 4` 计算结果是浮点数。

编译器通过类型推导来决定 `v1` 和 `v2` 的类型。

#### 2. **表达式的值类别**

值类别描述了表达式是否产生一个值、函数或对象，并且该值或对象是否是可识别的。C++ 中的值类别帮助我们理解如何使用表达式。

在 C++11 之前，C++ 只区分了两种值类别：左值（lvalue）和右值（rvalue）。在 C++11 中，新增了三个值类别以支持移动语义，但在本章中我们将专注于左值和右值，后续会深入讨论移动语义。

### **左值（lvalue）与右值（rvalue）**

#### **左值（lvalue）**

**左值（lvalue）** 是指计算为具有持久性的对象或函数的表达式。左值有明确的身份，可以通过标识符、引用或指针访问，且通常在其生命周期内存在。

例如：

```cpp
int main() {
    int x { 5 };
    int y { x };  // x 是左值表达式
    return 0;
}
```

在上面的例子中，`x` 是一个左值，因为它是一个具有明确标识符（`x`）的对象。

**左值的分类：**
- **可修改左值**：可以改变其值的左值。例如，普通变量 `x`。
- **不可修改左值**：不能改变其值的左值。例如，`const` 变量。

```cpp
int main() {
    int x {};           // 可修改左值
    const double d {};  // 不可修改左值

    int y { x };        // x 是可修改的左值表达式
    const double e { d }; // d 是不可修改的左值表达式
    return 0;
}
```

#### **右值（rvalue）**

**右值（rvalue）** 是指计算为一个值的表达式，通常不具有持久性。右值不指向一个明确的对象，它们在表达式结束时会被丢弃。

例如：

```cpp
int return5() {
    return 5;
}

int main() {
    int x { 5 };         // 5 是右值表达式
    const double d { 1.2 }; // 1.2 是右值表达式
    int z { return5() }; // return5() 是右值表达式
    int w { x + 1 };     // x + 1 是右值表达式
    return 0;
}
```

在这段代码中：
- `5` 和 `1.2` 是字面值，属于右值。
- `return5()` 和 `x + 1` 也是右值，因为它们计算出的是临时的结果。

#### **为什么 `x = 5` 是有效的，而 `5 = x` 是无效的**

赋值操作要求：
- **左操作数必须是可修改的左值**。
- **右操作数必须是右值**。

因此，`x = 5` 是有效的，因为 `x` 是可修改的左值，`5` 是右值。而 `5 = x` 无效，因为 `5` 是右值，不能作为赋值的左操作数。

```cpp
int main() {
    int x {};
    x = 5;  // 有效: x 是可修改的左值，5 是右值
    5 = x;  // error: 5 是右值表达式，不能作为左值
    return 0;
}
```

### **值类别的总结**

- **左值（lvalue）**：表示一个持久存在的对象，可以修改它的内容。左值可以通过引用或指针访问。
- **右值（rvalue）**：表示一个临时值，通常在表达式结束时丢弃。常见的右值包括字面值和函数返回值。

#### **经验法则：**
- **左值表达式**：计算为具有持久性且可以识别的对象，如变量和数组元素。
- **右值表达式**：计算为值并且没有持久性，如字面值、返回值、运算结果等。

### **左值到右值的转换**

在某些情况下，左值表达式会隐式地转换为右值。例如，在初始化时，左值 `x` 会转为右值，作为初始化另一个变量的值：

```cpp
int main() {
    int x { 5 };
    int y { x };  // x 是左值表达式，但会隐式转换为右值
    return 0;
}
```

**左值到右值的转换** 发生在需要右值的上下文中。例如，在赋值语句中，右侧的表达式可以是左值，但它会被转换为右值：

```cpp
int main() {
    int x { 1 };
    int y { 2 };
    x = y;  // y 是左值，但会转换为右值，计算为 2 后赋值给 x
    return 0;
}
```

### **常见右值表达式**
- **字面值**：如整数、浮点数、字符串字面值（`"abc"` 也是左值，但 C 样式字符串字面值是右值）。
- **临时变量**：例如，`x + 1`，这会产生一个临时的右值。
- **函数返回值**：如 `return 5` 的返回值。

---

### **总结**

| 表达式类型 | 描述                                  | 示例                           |
|------------|---------------------------------------|--------------------------------|
| **左值（lvalue）** | 计算为持久存在的对象，通常具有标识符 | `int x = 5;`                   |
| **右值（rvalue）** | 计算为一个值，且没有持久性           | `5`, `x + 1`, `return5()`      |

通过理解左值和右值的概念，我们能更清楚地掌握 C++ 中的赋值规则、内存管理和优化技巧（如移动语义）。
