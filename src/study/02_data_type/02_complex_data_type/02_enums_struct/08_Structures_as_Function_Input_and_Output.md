### 结构体作为函数的输入与输出

结构体在函数参数传递和返回值传递方面起到了重要的作用。它不仅能使代码更加简洁，而且增强了代码的可维护性。通过结构体，我们可以将多个相关的变量打包成一个单一的对象，方便在函数间传递和处理。

#### 1. 通过结构体传递多个参数

考虑一个包含多个属性的对象，例如员工（`Employee`）。在没有结构体的情况下，我们通常需要单独传递每个成员变量。例如：

```cpp
int main()
{
    int id { 1 };
    int age { 24 };
    double wage { 52400.0 };
    
    // 传递三个变量给函数
    printEmployee(id, age, wage);
    
    return 0;
}
```

上述代码虽然不复杂，但在实际开发中，如果要处理多个员工的信息，每次传递多个变量给函数将变得繁琐且容易出错。若添加新的属性（例如 `name`）时，所有相关的函数和调用都需要修改，这会大大增加维护难度。

#### 2. 通过结构体传递对象

使用结构体可以将多个变量打包成一个对象传递给函数。结构体通常通过**引用传递**，以避免不必要的内存复制。下面是改进后的代码：

```cpp
#include <iostream>

struct Employee
{
    int id {};
    int age {};
    double wage {};
};

void printEmployee(const Employee& employee) // 通过引用传递
{
    std::cout << "ID:   " << employee.id << '\n';
    std::cout << "Age:  " << employee.age << '\n';
    std::cout << "Wage: " << employee.wage << '\n';
}

int main()
{
    Employee joe { 14, 32, 24.15 };
    Employee frank { 15, 28, 18.27 };

    // 打印 Joe 的信息
    printEmployee(joe);

    std::cout << '\n';

    // 打印 Frank 的信息
    printEmployee(frank);

    return 0;
}
```

**优势：**
- 通过结构体传递，不必将每个成员变量作为单独的参数传递，代码更加简洁。
- 若需要为 `Employee` 添加新属性（如 `name`），只需修改 `Employee` 结构体，不需要修改函数定义或调用。

结构体作为函数输入的一个关键优势是，**新成员自动包含在结构体中，无需更改函数接口**。

#### 3. 结构体作为返回值

有时我们需要返回一个包含多个数据的对象，但函数只能返回一个单一的值。此时，结构体是一个非常理想的选择。假设我们需要返回一个三维空间中的点：

```cpp
#include <iostream>

struct Point3d
{
    double x { 0.0 };
    double y { 0.0 };
    double z { 0.0 };
};

Point3d getZeroPoint()
{
    // 创建一个临时变量并返回
    Point3d temp { 0.0, 0.0, 0.0 };
    return temp;
}

int main()
{
    Point3d zero{ getZeroPoint() };

    if (zero.x == 0.0 && zero.y == 0.0 && zero.z == 0.0)
        std::cout << "The point is zero\n";
    else
        std::cout << "The point is not zero\n";

    return 0;
}
```

**输出：**
```
The point is zero
```

在这个例子中，`getZeroPoint()`函数创建一个 `Point3d` 结构体对象 `temp`，然后返回该对象。结构体作为返回值的好处是，它能够将多个相关值打包到一个单一的返回对象中。

#### 4. 返回结构体的优化

上面的代码可以进一步简化，不必显式创建临时变量 `temp`。直接返回一个匿名的临时对象：

```cpp
Point3d getZeroPoint()
{
    return Point3d { 0.0, 0.0, 0.0 }; // 返回一个未命名的 Point3d
}
```

这里，我们直接返回一个临时的 `Point3d` 对象，简化了代码，也避免了不必要的命名和变量。

#### 5. 返回类型推导

如果函数已经声明了返回类型，C++允许在 `return` 语句中省略返回类型，直接返回一个初始化的结构体：

```cpp
Point3d getZeroPoint()
{
    return { 0.0, 0.0, 0.0 }; // 返回一个未命名的 Point3d
}
```

这种方法更加简洁，且依赖于返回类型的推导。编译器根据函数的返回类型推导出正确的返回值类型。

#### 6. 空大括号返回值初始化

对于结构体的返回值，还可以使用空大括号 `{}` 来进行值初始化。它会自动将结构体的所有成员初始化为零：

```cpp
Point3d getZeroPoint()
{
    return {}; // 使用空大括号进行值初始化
}
```

这种初始化方法通常用于构造一个没有显式初始化值的结构体对象，其成员会被默认初始化为零。

---

### 结构体是代码中的重要组件

结构体作为一种数据封装方式，在C++中是非常重要的，尤其是在编写函数接口时。它们能够将多个相关的变量组合成一个单一对象，减少了函数参数的数量，增强了代码的可维护性。

结构体的概念为类的实现提供了基础。类是面向对象编程的核心概念，它直接建立在结构体的概念之上。因此，良好理解结构体的使用，尤其是成员的初始化、传递和返回等操作，有助于顺利过渡到类的使用。

---

### 总结

- **结构体作为函数参数**：通过结构体传递多个相关变量，比单独传递每个变量更加简洁、易于维护。
- **结构体作为返回值**：结构体允许函数返回多个值，从而避免函数只能返回单一变量的限制。
- **引用传递**：结构体通常通过引用传递，以避免复制成本，尤其是结构体包含较多成员时。
- **返回类型推导与初始化**：结构体可以通过返回类型推导来简化函数声明，使用空大括号进行值初始化确保成员被正确初始化。

通过掌握结构体的这些应用，能够使代码更加模块化、清晰，便于扩展与维护。
