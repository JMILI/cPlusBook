### 用户自定义类型简介

在C++中，基本类型（如`int`、`double`等）被定义为语言核心的一部分，直接可以使用。这些基本类型包括变量、函数、指针、引用以及数组等复合类型，都是C++已知的，并且可以直接定义和使用。比如：

```cpp
int x;         // 定义一个基本类型 int 的变量
double d;      // 定义一个基本类型 double 的变量
void fcn(int); // 定义一个返回类型为 void，参数类型为 int 的函数
int* ptr;      // 定义一个指向 int 的指针
int& ref { x }; // 定义一个引用变量 ref，引用 x
int arr[5];    // 定义一个包含五个 int 的数组
```

在这些例子中，C++已经知道如何处理这些类型及其相关操作。

### 类型别名

C++允许我们为现有类型创建别名，使得代码更具可读性或表达特定的语义。例如：

```cpp
using length = int;  // 为 int 类型定义别名 length

int main()
{
    length x { 5 }; // 使用 length 作为 int 的别名
    std::cout << x << '\n'; // 输出 5

    return 0;
}
```

这段代码通过 `using` 关键字为 `int` 类型创建了别名 `length`。这样，你就可以用 `length` 代替 `int` 来定义变量。值得注意的是，定义类型别名并不创建新的类型或对象，它只是告诉编译器如何理解新的标识符。

### 用户定义类型

C++允许我们根据需求创建新的类型，这些类型称为用户定义类型。用户自定义类型并不是C++语言本身定义的，而是程序员自定义的。这允许开发者根据实际问题创建更加符合需求的数据结构。

比如，创建一个分数类型 `Fraction`：

```cpp
// 定义一个新的类型 Fraction
struct Fraction
{
    int numerator {};   // 分子
    int denominator {}; // 分母
};

int main()
{
    Fraction f{ 3, 4 }; // 创建一个类型为 Fraction 的变量 f，分子为3，分母为4
    return 0;
}
```

这段代码定义了一个新的类型 `Fraction`，它包含两个成员变量：`numerator` 和 `denominator`，分别代表分数的分子和分母。在 `main()` 函数中，我们实例化了一个 `Fraction` 类型的变量 `f`，并初始化它的成员变量。

### 程序定义类型的命名惯例

对于程序定义的类型，通常遵循以下命名约定：
- 类型名以大写字母开头。
- 不使用后缀（例如 `Fraction_t` 是不推荐的）。

例如：
```cpp
Fraction fraction {}; // 类型名 Fraction 大写，变量名 fraction 小写
```

这种命名风格有助于区分程序定义类型和变量名，避免混淆。

### 在多文件程序中使用程序定义类型

当程序定义类型在多个文件中使用时，通常将类型的定义放在头文件中，然后通过 `#include` 将其引入需要的文件。这保证了所有的代码文件都可以看到完整的类型定义。

例如，创建一个 `fraction.h` 头文件：

**fraction.h:**
```cpp
#ifndef FRACTION_H
#define FRACTION_H

// 定义一个类型 Fraction
struct Fraction
{
    int numerator {};   // 分子
    int denominator {}; // 分母
};

#endif
```

然后在其他文件中引用它：

**fraction.cpp:**
```cpp
#include "fraction.h" // 包含 Fraction 的定义

int main()
{
    Fraction f{ 3, 4 }; // 创建一个 Fraction 类型的对象 f
    return 0;
}
```

### 类型定义部分豁免了单定义规则（ODR）

C++语言有一个单定义规则（ODR），要求每个函数和全局变量在程序中只能有一个定义。然而，类型定义部分是豁免于这一规则的。也就是说，我们可以在多个代码文件中定义和使用相同的类型，只要它们的定义保持一致。

### 用户定义类型与程序定义类型

C++标准中有时提到“用户定义类型”，通常这指的是由程序员创建的类类型和枚举类型（包括标准库中的类型）。例如，`std::string` 这种标准库中的类类型也是“用户定义类型”。但在日常对话中，“程序定义类型”这个术语更加精确，专指我们自己定义的类类型和枚举类型。

总结一下：

| 类别         | 含义 | 示例 |
|--------------|------|------|
| 基本类型     | C++语言核心类型 | `int`, `std::nullptr_t` |
| 复合类型     | 基本类型的组合 | `int&`, `double*`, `std::string`, `Fraction` |
| 用户定义类型 | 由标准库或实现定义的类类型和枚举类型 | `std::string`, `Fraction` |
| 程序定义类型 | 我们自己定义的类类型和枚举类型 | `Fraction` |

### 最佳实践

- 自定义类型的命名应该以大写字母开头，不使用后缀。
- 如果自定义类型只在一个文件中使用，最好在该文件中定义，并靠近首次使用点。
- 如果自定义类型在多个文件中使用，最好将其放入头文件中，并通过 `#include` 引入。
