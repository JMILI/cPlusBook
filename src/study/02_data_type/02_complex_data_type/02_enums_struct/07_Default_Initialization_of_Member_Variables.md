### 结构体成员的默认初始化

在C++中，我们可以为结构体（或类）的成员变量提供默认初始化值。这项技术被称为**非静态成员初始化**，初始化的默认值称为**默认成员初始值设定项**。这种方法允许在结构体类型定义时为成员指定默认值，从而简化对象实例化时的初始化操作。

#### 示例：成员变量的默认初始化

```cpp
struct Something {
    int x;       // 无默认初始值 (不推荐)
    int y {};    // 值初始化
    int z { 2 }; // 显式的默认值
};

int main() {
    Something s1; // s1.x 未初始化, s1.y 为 0, s1.z 为 2
    return 0;
}
```

在上面的例子中：
- `x` 没有默认值，因此它保持未初始化状态（**未定义行为**，不推荐）。
- `y` 使用值初始化，因此被初始化为 0。
- `z` 被显式初始化为 2，作为默认值。

#### 为什么需要默认初始化？

1. **避免未初始化的成员**：
   如果某个成员没有默认初始化，而程序没有显式为其提供初始值，那么该成员的值就是未定义的，这可能会导致难以预料的行为。为每个成员提供一个默认值可以避免这种情况。

2. **简化对象的创建**：
   当我们创建一个结构体对象时，即使没有显式提供所有成员的初始值，默认值仍然可以确保所有成员都有一个合理的初始状态。

#### 高级概念：CTAD和非静态成员初始化

C++中的**类模板参数推导（CTAD）**不能用于非静态成员初始化。也就是说，在定义结构体类型时，成员的默认值不能由模板参数自动推导。

---

### 显式初始化值优先于默认值

当我们使用初始化列表来创建结构体对象时，显式提供的初始值将优先于默认值。如果显式给出一个值，则不会使用成员的默认值。

#### 示例：显式初始化值优先

```cpp
struct Something {
    int x;       // 无默认初始值
    int y {};    // 值初始化
    int z { 2 }; // 显示设置初始值
};

int main() {
    Something s2 { 5, 6, 7 }; // 显式初始化: s2.x, s2.y, 和 s2.z 设置为 5, 6, 7
    return 0;
}
```

在这个例子中，`s2.x`、`s2.y` 和 `s2.z` 都被显式初始化为 5、6 和 7。因此，尽管 `z` 有默认值 2，但它被显式初始化为 7。

---

### 默认初始化与值初始化的关系

在C++中，存在两种常见的初始化方式：**默认初始化**和**值初始化**。这两种方式有时会产生相同的结果，尤其是在结构体中。

#### 默认初始化
如果没有显式的初始化值，且成员具有默认值，则使用该默认值。

#### 值初始化
当我们使用 `{}` 来初始化一个对象时，所有成员将会被初始化为其类型的**默认值**。对于基本数据类型（如 `int`），这意味着它们会被初始化为零。

#### 示例：默认初始化与值初始化

```cpp
struct Something {
    int x;       // 无默认初始值
    int y {};    // 值初始化
    int z { 2 }; // 显示设置初始值
};

int main() {
    Something s3 {};  // 值初始化: s3.x 为 0, s3.y 为 0, s3.z 为 2
    return 0;
}
```

在上面示例中，`s3.x` 被值初始化为 0，因为它没有默认值，而 `s3.y` 和 `s3.z` 使用默认值（0和2）。

---

### 缺少初始化值时，如何使用默认值

如果在初始化时提供的成员变量数量小于结构体中的成员数量，编译器将根据成员变量的默认值进行初始化。

#### 示例：缺少初始化值的情况

```cpp
struct Something {
    int x;       // 无默认初始值
    int y {};    // 值初始化
    int z { 2 }; // 显示设置初始值
};

int main() {
    Something s4 { 5 };  // 只为 x 提供了初始化值，y 使用默认值 0，z 使用默认值 2
    return 0;
}
```

在这个例子中，由于缺少对 `y` 和 `z` 的初始化值，`y` 会被值初始化为 0，`z` 使用默认值 2。

---

### 最佳实践：始终为成员提供默认值

为了避免未初始化成员变量的潜在风险，**最好为每个成员提供一个默认值**。这不仅能确保无论是否使用初始化列表，成员都有一个有效的初始值，还能使代码更加健壮。

#### 示例：为所有成员提供默认值

```cpp
struct Fraction {
    int numerator { }; // 默认为 0
    int denominator { 1 }; // 默认为 1
};

int main() {
    Fraction f1;          // f1.numerator 为 0, f1.denominator 为 1
    Fraction f2 {};       // f2.numerator 为 0, f2.denominator 为 1
    Fraction f3 { 6 };    // f3.numerator 为 6, f3.denominator 为 1
    Fraction f4 { 5, 8 }; // f4.numerator 为 5, f4.denominator 为 8

    return 0;
}
```

在这个例子中，无论如何创建 `Fraction` 类型的对象，成员变量始终有一个初始化值，避免了未初始化的风险。

---

### 聚合类型的默认初始化与值初始化

对于**聚合类型**（即没有用户定义构造函数、虚函数或私有成员的结构体、类或联合体），C++提供了两种初始化方式：**默认初始化**和**值初始化**。通常，**值初始化**是更推荐的方式，因为它可以确保所有成员都被初始化，尤其是那些没有提供默认值的成员。



- **默认初始化**：如果成员有默认值，则使用默认值初始化。
- **值初始化**：所有成员都将被初始化为其类型的零值。

#### 推荐做法
对于聚合类型，**首选值初始化**（即使用 `{}`）而不是默认初始化，这样可以确保每个成员都被正确初始化。

---

### 总结

- **默认成员初始值设定项**：为结构体成员提供默认值，避免成员未初始化。
- **显式初始化值优先**：如果初始化列表中显式提供了值，则不会使用默认值。
- **值初始化**：推荐使用 `{}` 进行值初始化，以确保成员被初始化为其类型的零值。
- **最佳实践**：始终为结构体成员提供默认值，以避免未初始化的问题。
