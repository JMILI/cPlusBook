### 控制流简介
**定义**：控制流指程序中代码的执行顺序，包含顺序结构、选择结构（分支）和循环结构。  
**案例**：函数调用、条件判断（`if`）、循环（`for`）。  
**常用场景**：任何需要动态决策或重复操作的场景。  
**优点**：灵活控制程序逻辑。  
**缺点**：复杂控制流可能降低可读性。  
**最佳实践**：减少嵌套层级，优先使用结构化控制流（如避免 `goto`）。

---

### If语句与代码块
**定义**：`if` 根据条件执行代码块，`else` 提供备选分支。  
**案例**：
```cpp
if (x > 0) {
    cout << "Positive";
} else if (x < 0) {
    cout << "Negative";
} else {
    cout << "Zero";
}
```
**常用场景**：条件执行、错误检查。  
**优点**：直观表达分支逻辑。  
**缺点**：多层嵌套易导致代码臃肿。  
**最佳实践**：始终使用大括号，明确作用域。

---

### 常见的if语句问题
**定义**：常见错误包括悬空 `else`、赋值符误用（`=` 代替 `==`）、作用域混淆。  
**案例**：
```cpp
if (x = 0)  // 错误：赋值而非比较
    cout << "x is 0";
```
**常用场景**：初学者的代码。  
**缺点**：隐蔽的逻辑错误。  
**最佳实践**：启用编译器警告（如 `-Wall`），使用静态分析工具。

---

### Constexpr if语句
**定义**：C++17 特性，编译时条件判断，仅保留符合条件的代码分支。  
**案例**：
```cpp
template<typename T>
void print(T val) {
    if constexpr (std::is_pointer_v<T>) {
        cout << *val;
    } else {
        cout << val;
    }
}
```
**常用场景**：模板元编程、编译时优化。  
**优点**：消除运行时开销。  
**缺点**：仅支持 C++17 及以上。  
**最佳实践**：用于类型或编译时常量条件。

### Switch语句基础
**定义**：基于整型或枚举值的多分支选择结构。  
**案例**：
```cpp
switch (color) {
    case RED:   cout << "Red"; break;
    case BLUE:  cout << "Blue"; break;
    default:    cout << "Unknown";
}
```
**常用场景**：枚举处理、状态机。  
**优点**：比多层 `if-else` 更清晰。  
**缺点**：仅支持整型/枚举类型。  
**最佳实践**：始终包含 `default` 分支。

---

### Switch Fallthrough机制与作用域
**定义**：`case` 分支未加 `break` 时，代码会继续执行后续分支（fallthrough）。  
**案例**：
```cpp
switch (c) {
    case 'a':
    case 'e':  // 共享处理逻辑
        cout << "Vowel";
        break;
    default:
        cout << "Consonant";
}
```
**常用场景**：共享逻辑的分支。  
**优点**：减少重复代码。  
**缺点**：意外 fallthrough 导致错误。  
**最佳实践**：用 `[[fallthrough]]` 显式标记，或用 `{}` 限制变量作用域。

### Goto语句
**定义**：无条件跳转到指定标签，破坏结构化编程。  
**案例**：
```cpp
void func() {
    if (error) goto cleanup;
    // ...
cleanup:
    releaseResources();
}
```
**常用场景**：错误处理、跳出深层嵌套。  
**优点**：简化资源清理逻辑。  
**缺点**：破坏代码可读性。  
**最佳实践**：仅在关键路径（如性能敏感代码）中谨慎使用。

---

### 循环和while语句简介
**定义**：`while` 在条件为真时重复执行代码块。  
**案例**：
```cpp
while (input != "quit") {
    cin >> input;
    process(input);
}
```
**常用场景**：不确定次数的循环（如读取输入）。  
**优点**：灵活处理动态条件。  
**缺点**：可能死循环。  
**最佳实践**：确保循环条件最终变为假。

---

### Do while语句
**定义**：先执行代码块，再检查条件，保证至少执行一次。  
**案例**：
```cpp
do {
    cin >> password;
} while (!isValid(password));
```
**常用场景**：输入验证、至少执行一次的操作。  
**优点**：确保代码块执行。  
**缺点**：可能误用导致冗余执行。  
**最佳实践**：仅用于必须执行一次的场景。

---

### For语句
**定义**：通过初始化、条件、迭代表达式控制循环。  
**案例**：
```cpp
for (int i=0; i<10; i++) {
    cout << i << endl;
}
```
**常用场景**：已知次数的循环、遍历容器。  
**优点**：紧凑控制循环变量作用域。  
**缺点**：语法较复杂。  
**最佳实践**：优先使用 C++11 范围 `for`：
```cpp
for (auto& item : vec) { ... }
```

---

### Break与Continue
**定义**：`break` 退出循环，`continue` 跳过当前迭代。  
**案例**：
```cpp
for (int i=0; i<10; i++) {
    if (i == 5) break;     // 退出循环
    if (i % 2 == 0) continue; // 跳过偶数
    cout << i;
}
```
**常用场景**：提前终止循环或跳过无效数据。  
**优点**：简化循环控制逻辑。  
**缺点**：滥用可能导致代码难以理解。  
**最佳实践**：避免在多层嵌套中使用。

---

### 提前退出程序
**定义**：通过 `exit()` 或 `return` 立即终止程序。  
**案例**：
```cpp
if (fatalError) {
    cerr << "Error occurred";
    exit(EXIT_FAILURE);
}
```
**常用场景**：致命错误处理。  
**优点**：快速终止程序。  
**缺点**：可能跳过资源释放。  
**最佳实践**：在 `main` 中使用 `return`，其他函数慎用 `exit()`。
