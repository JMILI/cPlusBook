### 字面值和操作符简介

#### 字面值

字面值（或称为字面常量）是直接写入源代码中的固定值，例如 `"Hello world!"` 和 `5`。它们在编译时被嵌入到可执行文件中，并且其值不可更改。

- **例子**：
  ```cpp
  std::cout << "Hello world!"; // 打印字面值 "Hello world!"
  int x { 5 };                 // 使用字面值初始化变量x
  ```

与变量不同，字面值的值是固定的，在程序运行期间不会改变。这意味着字面值实际上是常量，而变量可以在程序执行过程中被修改。

- **关键点**：字面值是直接插入到源代码中的值，它们直接出现在可执行代码中（除非被优化）。对象和变量表示保存值的内存位置，这些值按需获取。

#### 操作符

操作符是对一个或多个操作数执行特定运算并产生结果的过程。常见的操作符包括数学运算符、赋值操作符以及输入输出操作符等。

- **标准算术操作符**：加法 (`+`)、减法 (`-`)、乘法 (`*`) 和除法 (`/`)。
- **一元操作符**：作用于单个操作数，如 `-`（负号）。
- **二元操作符**：作用于两个操作数，如 `+`（加法）、`-`（减法）。
- **三元操作符**：C++中唯一的三元操作符是条件操作符 `?:`。
- **零元操作符**：没有操作数的操作符，如 `throw`。

**例子**：

```cpp
#include <iostream>

int main() {
    std::cout << 1 + 2 << '\n'; // 输出3，使用了加法操作符+
    return 0;
}
```

在这个例子中，字面值 `1` 和 `2` 是加法操作符 `+` 的操作数，产生的输出值为 `3`。

**操作符链接**：操作符可以链式使用，例如 `2 * 3 + 4`，首先计算乘法得到 `6`，然后加上 `4` 得到最终结果 `10`。

**返回值和副作用**：
- 大多数操作符产生一个返回值（例如，`2 + 3` 返回 `5`）。
- 某些操作符具有副作用，比如赋值操作符 `=` 将值赋予变量，或者 `std::cout <<` 将内容输出到控制台。

**高级用法**：
- 操作符 `=` 和 `<<` 返回左操作数，允许链式调用，例如 `x = y = 5` 和 `std::cout << "Hello" << "world"`。

- **例子**：
  ```cpp
  int x, y;
  x = y = 5; // 首先y=5，然后x=y，最终x和y都等于5
  
  std::cout << "Hello" << "world"; // 先打印"Hello"，再打印"world"
  ```

通过理解字面值和操作符的基本概念及其应用，可以更有效地编写清晰且功能强大的C++代码。记住，操作符不仅可以用于计算，还可以用来实现复杂的逻辑和数据处理任务。
