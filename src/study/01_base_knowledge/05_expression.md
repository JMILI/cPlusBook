### 表达式简介

在C++中，表达式是使用字面值常量、变量、运算符和函数调用的组合来计算一个新值的基本构建块。执行表达式的过程称为求值，其结果是一个单一的值。

#### 表达式的定义与示例

表达式可以包含以下元素：

- **字面值常量**：如 `2` 或 `"Hello world!"`
- **变量**：如 `x`
- **运算符**：如 `+`, `-`, `*`, `/`
- **函数调用**：如 `five()`

**示例代码**：

```cpp
int five() {
    return 5;
}

int main() {
    int a{ 2 };             // 使用字面值常量初始化 a
    int b{ 2 + 3 };         // 使用计算后的结果初始化 b
    int c{ (2 * 3) + 4 };   // 使用计算后的结果初始化 c
    int d{ b };             // 使用变量 b 的值初始化 d
    int e{ five() };        // 使用函数的返回值初始化 e

    return 0;
}
```

上述代码展示了如何使用不同类型的表达式来初始化变量。

#### 表达式的求值过程

- **字面值常量**：直接作为自身的值，例如 `2` 求值为 `2`。
- **变量**：求值为其存储的值，例如 `x` 求值为 `x` 中的值。
- **运算符**：根据操作数进行相应的计算，例如 `2 + 3` 求值为 `5`。
- **函数调用**：求值为函数的返回值，例如 `five()` 求值为 `5`。

涉及副作用的表达式（如赋值或I/O操作）不仅产生一个值，还可能修改程序的状态。例如，`x = 5` 赋值给 `x` 并且该表达式的结果也是 `x`。

#### 表达式语句

表达式不能单独存在，必须作为语句的一部分。表达式后面加上分号就形成了一个表达式语句。例如：

```cpp
x = 5; // 表达式语句
```

即使表达式有副作用（如赋值），其生成的返回值通常被丢弃。

**无用的表达式语句**：

某些表达式语句虽然语法正确但没有实际效果，例如 `2 * 3;`。这种情况下，编译器可能会发出警告。

#### 子表达式、完整表达式和复合表达式

- **子表达式**：嵌套在其他表达式中的表达式。例如，在 `x = 4 + 5` 中，`4 + 5` 是 `x = 4 + 5` 的子表达式。
- **完整表达式**：独立存在的表达式，不作为其他表达式的子部分。例如，`2 + 3` 和 `x = 4 + 5` 都是完整表达式。
- **复合表达式**：包含两个或多个运算符的表达式。例如，`x = 4 + 5` 是复合表达式，因为它包含了 `=` 和 `+` 两个运算符。

**总结**：

理解表达式的概念及其分类有助于编写清晰、高效的C++代码。通过掌握表达式的求值规则以及如何将表达式转换为语句，你可以更好地控制程序的行为并避免常见的编程错误。此外，了解子表达式、完整表达式和复合表达式的区别可以帮助你更深入地分析复杂的表达式结构。
