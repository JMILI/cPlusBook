# 要点总结

### 1.函数重载简介

### 2.被重载函数之间互相区分

- **参数数量**：不同的参数数量可以使函数被区分。
- **参数类型**：不同的参数类型（排除类型别名和`const`限定符）也是区分重载函数的有效方式。
- **返回类型**：不能依赖返回类型来区分重载函数。
- **名称修饰**：了解名称修饰有助于理解为什么重载函数可以在编译后的代码中被唯一识别。

### 3.函数重载决议

- 编译器按优先级顺序逐步尝试匹配。
- 精确匹配 > 数值提升 > 数值转换 > 用户定义转换。
- 歧义产生于同一阶段的多个匹配。
- 多参数需每个参数至少不劣于其他候选，且至少一个更优。


### 4.函数的delete说明符

`=delete`避免不期望的参数类型调用函数。通过合理使用它和函数模板，可以更灵活地管理函数的重载和调用规则。

### 5.默认参数

- 一旦声明了默认参数，就不能在同一文件中重新声明。对于有前向声明和函数定义的函数，默认参数可以在前向声明或函数定义中单独声明，但不能同时在两者中声明。

### 6.函数模板

- 模板参数命名 以前缀`T`开始，如`TAllocator`，建议使用以`T`开头的单个大写字母来命名模板类型参数

### 7.函数模板实例化

- 函数模板本身不是函数，其代码不会直接编译或执行，它的主要作用是生成函数。
- 模板函数定义，调用
- 实例化规则：对于首次调用的函数进行实例化，再次调用，会路由到已实例化的函数，如果没有函数模板调用，不执行实例化
- 在多个文件中使用函数模板：将所有模板代码放在头（`.h`）文件中
- 函数模板推导需要调用的函数，
```c++
template <typename T>
T max(T x, T y) {
    std::cout << "called max<int>(int, int)\n";
    return (x < y) ? y : x;
}

//调用
std::cout << max<int>(1, 2) << '\n'; // 调用max<int>(int, int)
std::cout << max<>(1, 2) << '\n';    // 推导 max<int>(int, int) (不考虑非模版函数)
std::cout << max(1, 2) << '\n';      // 调用 max(int, int)   这种优先考虑非模板函数
```
- 实例化函数不一定通过编译
- 优点：减少代码维护工作和错误
- 缺点：难读的错误消息，代码膨胀和编译时间变慢

### 8.具有多个模板类型的函数模板

- 多个模板类型的函数模板定义:
```c++
template <typename T, typename U>
auto max(T x, U y) {
    return (x < y) ? y : x;
}
```
- C++20 auto简化函数模板:
```c++
auto max(auto x, auto y) {
    return (x < y) ? y : x;
}
```

### 9.非类型模板参数 

- 非类型模板参数：具有固定类型的模板参数，它作为模板参数传入的 `constexpr` 值的占位符。可以理解为编译器确定的一个数值类型
  1. **整型**
  2. **枚举类型**
  3. **std::nullptr_t**
  4. **浮点类型（自 C++20）**
  5. **指向对象的指针或引用**
  6. **指向函数的指针或引用**
  7. **指向成员函数的指针或引用**
  8. **字面值类类型（自 C++20）**
- 案例：
```cpp
#include <iostream>

template <int N> // 声明一个非类型模板参数，类型是 int 名称是 N
void print()
{
    std::cout << N << '\n'; // 在这里使用N
}

int main()
{
    print<5>(); // 5 是传入的非类型模板参数

    return 0;
}
```
- 非类型模板参数的用途:在编译器就排除一些错误
- 非类型模板参数常见的允许类型转换：
  1. **整形提升（例如从 `char` 到 `int`）**
  2. **整形转换（例如，`char` 到 `long` 或 `int` 到 `char`）**
  3. **用户自定义的转换（例如，自定义的类到 `int`）**
  4. **左值到右值的转换（例如，变量 `x` 转换为变量 `x` 的值）**
- C++17 auto可以对非类型模板参数进行类型推导
