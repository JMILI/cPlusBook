### 字面值常量

字面值是直接嵌入到代码中的值。例如：

```cpp
return 5;                     // 5 是整数字面值
bool myNameIsAlex { true };   // true 是布尔字面值
double d { 3.4 };             // 3.4 是双精度浮点字面值
std::cout << "Hello, world!"; // "Hello, world!" 是 C 语言风格的字符串字面值
```

字面值有时被称作字面值常量，因为它们的值无法重新定义（5 始终表示整数值 5）。

#### 字面值的类型

就像对象有类型一样，所有字面值也都有类型。字面值的类型是从字面值的值推导出来的。例如，整数形式的字面值（如 5）会被推断为 `int` 类型。

默认情况下：

| 字面值 | 示例 | 类型 |
| ---- | ---- | ---- |
| 整数 | 5、0、 - 3 | `int` |
| 布尔值 | `true`、`false` | `bool` |
| 浮点数 | 1.2、0.0、3.4 | `double`（不是 `float`！） |
| 字符 | `'a'`、`'\n'` | `char` |
| C 语言风格的字符串 | `"Hello, world!"` | `const char[14]` |

#### 字面值后缀

如果字面值的默认类型不符合需求，可以通过添加后缀来更改字面值的类型：

| 类别 | 后缀 | 类型 |
| ---- | ---- | ---- |
| 整数类型 | `u` 或 `U` | `unsigned int` |
| 整数类型 | `l` 或 `L` | `long` |
| 整数类型 | `ul`、`uL`、`Ul`、`UL`、`lu`、`lU`、`Lu`、`LU` | `unsigned long` |
| 整数类型 | `ll` 或 `LL` | `long long` |
| 整数类型 | `ull`、`uLL`、`Ull`、`ULL`、`llu`、`llU`、`LLu`、`LLU` | `unsigned long long` |
| 整数类型 | `z` 或 `Z` | `std::size_t` 的有符号版本（C++23） |
| 整数类型 | `uz`、`uZ`、`Uz`、`UZ`、`zu`、`zU`、`Zu`、`ZU` | `std::size_t`（C++23） |
| 浮点类型 | `f` 或 `F` | `float` |
| 浮点类型 | `l` 或 `L` | `long double` |
| 字符串 | `s` | `std::string` |
| 字符串 | `sv` | `std::string_view` |

大多数后缀不区分大小写。由于小写的 `l` 在某些字体中看起来像数字 1，因此一些开发者更喜欢使用大写的字面值后缀。

**最佳实践**

优先使用大写的字面值后缀 `L`，而非小写的 `l`。

#### 整型字面值

通常不需要为整型字面值使用后缀，但以下是示例：

```cpp
#include <iostream>

int main()
{
    std::cout << 5 << '\n';  // 5（无后缀）是 `int` 类型（默认情况）
    std::cout << 5L << '\n'; // 5L 是 `long` 类型
    std::cout << 5u << '\n'; // 5u 是 `unsigned int` 类型

    return 0;
}
```

在大多数情况下，即使在初始化非 `int` 类型的整型变量时，也可以使用无后缀的 `int` 字面值：

```cpp
#include <iostream>

int main()
{
    int a { 5 };          // 可以：类型匹配
    unsigned int b { 6 }; // 可以：编译器会将数字转换为 `unsigned int` 类型
    long c { 7 };         // 可以：编译器会将数字转换为 `long` 类型

    return 0;
}
```

在这种情况下，编译器会将 `int` 类型转换为合适的类型。

#### 浮点字面值

默认情况下，浮点字面值的类型为 `double`。要使它们成为 `float` 字面值，应使用 `F`（或 `f`）后缀：

```cpp
#include <iostream>

int main()
{
    std::cout << 5.0 << '\n';  // 5.0（无后缀）是 `double` 类型（默认情况）
    std::cout << 5.0f << '\n'; // 5.0f 是 `float` 类型

    return 0;
}
```

新手程序员通常会对以下编译器警告感到困惑：

```cpp
float f { 4.1 }; // 警告：4.1 是双精度浮点字面值，不是单精度浮点字面值
```

因为 4.1 没有后缀，所以该字面值的类型是 `double`，而不是 `float`。当编译器确定字面值的类型时，它并不关心你对该字面值所做的操作（例如，在本例中，用它来初始化 `float` 变量）。由于字面值（`double` 类型）的类型与用来初始化的变量（`float` 类型）的类型不匹配，因此必须将该字面值转换为 `float` 类型，以便后续用于初始化变量 `f`。将值从 `double` 类型转换为 `float` 类型可能会导致精度损失，因此编译器会发出警告。

这里的解决方案可以是以下之一：

```cpp
float f { 4.1f }; // 使用 'f' 后缀声明字面值
double d { 4.1 }; // 将变量类型改为 `double`
```

#### 浮点字面值的科学表示法

声明浮点字面值有两种不同的方式：

```cpp
double pi { 3.14159 }; // 3.14159 是标准写法
double avogadro { 6.02e23 }; // 6.02 x 10^23 是科学计数法写法
```

在第二种形式中，指数后面的数字可以是负数：

```cpp
double electronCharge { 1.6e-19 }; // 电子的电荷量是 1.6 x 10^-19
```

#### 字符串常量

在编程中，字符串是用于表示文本（如名称、单词和句子）的连续字符的集合。

你编写的第一个 C++ 程序可能如下所示：

```cpp
#include <iostream>

int main()
{
    std::cout << "Hello, world!";
    return 0;
}
```

“Hello, world!” 是一个字符串字面值。字符串字面值放在双引号之间，以将它们标识为字符串（而字符字面值放在单引号之间）。

由于字符串通常在程序中使用，因此大多数现代编程语言都包含基本的字符串数据类型。由于历史原因，字符串不是 C++ 中的基本类型。相反，它们有一种奇怪、复杂的类型，很难使用（将在以后的课程中讨论）。这样的字符串通常称为 C 字符串或 C 风格的字符串，因为它们是从 C 语言继承而来的。

关于 C 风格的字符串字面值，有两件事值得了解。

- 所有的 C 字符串都有一个隐式的空字符结尾符。例如，"hello" 看起来只有五个字符，但实际上有 6 个：`'h'`、`'e'`、`'l'`、`'l'`、`'o'` 和 `'\0'`（ASCII 码为 0）。结尾的 `'\0'` 是一个特殊字符，即所谓的空字符结尾符，用于标记字符串的结束位置。
- 与其他大多数字面值常量（它们都是值，而非对象）不同，C 字符串是一个 `const` 对象，程序开始执行前会确保其存在，直到程序结束。在介绍 `std::string_view` 时会进一步说明。

与 C 风格字符串字面值不同，`std::string` 和 `std::string_view` 字面值会创建临时对象。这些临时对象会立即使用，并在创建它们的完整表达式的末尾被销毁。



**关键点**

C 风格字符串字面值是在程序开始时创建的常量对象，并保证在整个程序运行期间存在。


#### 魔数（Magic numbers）

魔数是指单看其值含义不明确，且以后可能需要更改的字面值（通常是数字）。

下面是两个显示魔数示例的语句：

```cpp
constexpr int maxStudentsPerSchool{ numClassrooms * 30 };
setMax(30);
```

在这些上下文中，字面值 30 是什么意思呢？在前一种情况下，你可能会猜到这是每个班级的学生数量，但这并不明显。在后者中，谁知道呢。我们必须查看函数才能知道它的作用。

在复杂的程序中，除非有注释来解释，否则很难推断字面值表示什么。

使用魔数通常被认为是不好的做法，因为单看值很难明确其用途，如果值需要更改，还会带来问题。假设学校购买了新课桌，使班级规模从 30 人提高到 35 人，程序需要相应地进行修改。

为此，我们需要将一个或多个字面值从 30 更新为 35。但哪些字面值需要更新呢？`maxStudentsPerSchool` 初始值中的 30 似乎很明显。但用作 `setMax()` 参数的 30 呢？这个 30 与其他 30 的含义相同吗？如果相同，则应更改。否则，它应该保持不变，否则我们可能会破坏程序。如果进行全局搜索和替换，则可能会在 `setMax()` 的参数不应更改时无意中更新该参数。因此，你必须检查字面值 30 出现的所有代码（其中可能有数百处），然后单独确定是否需要更改。这可能非常耗时（并且容易出错）。

幸运的是，通过使用命名常量，可以轻松解决上下文缺失和更新相关的问题：

```cpp
constexpr int maxStudentsPerClass { 30 };
constexpr int totalStudents{ numClassrooms * maxStudentsPerClass }; // 现在 30 的含义很明确了

constexpr int maxNameLength{ 30 };
setMax(maxNameLength); // 很明显这里的 30 是另外的意思
```

常量的名称提供了上下文，我们只需要在一个位置更新值，就可以在整个程序中同步更改该值。

请注意，魔数并不总是数字——它们也可以是其他类型的字面值（例如字符串）。

在明显不太可能改变的上下文中使用的字面值通常不被认为是魔数。值 - 1、0、0.0 和 1 通常用于以下上下文：

```cpp
int idGenerator { 0 };         // 可以：我们从 0 开始生成 ID
idGenerator = idGenerator + 1; // 可以：ID 加 1
```

其他数字在上下文中也可能是显而易见的（因此，不被认为是魔数）：

```cpp
int kmtoM(int km)
{
    return km * 1000; // 可以：显然 1000 是一个转换系数
}
```

**最佳实践**

在代码中避免使用魔数（改用 `constexpr` 变量）。
