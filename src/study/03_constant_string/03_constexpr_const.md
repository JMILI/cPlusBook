### `constexpr` 关键字

#### 1. **`constexpr` 的核心作用**
- **定义**：`constexpr` 用于声明变量为 **编译时常量**，要求其初始化值必须是 **常量表达式**。
- **强制编译时计算**：若初始化值不是常量表达式，编译器将报错（与 `const` 不同，`const` 允许运行时常量）。

#### 2. **`constexpr` 与 `const` 的区别**
| 特性                | `constexpr`                  | `const`                      |
|---------------------|------------------------------|------------------------------|
| **初始化要求**       | 必须用常量表达式初始化        | 可用常量表达式或运行时表达式初始化 |
| **是否为编译时常量** | 一定是编译时常量              | 可能是编译时常量或运行时常量    |
| **优化确定性**       | 确保编译器优化                | 依赖初始化值的确定性            |

#### 3. **使用场景**
- **使用 `constexpr`**  
  当变量的值在编译时已知且不修改时（如数学常量、固定配置）：
  ```cpp
  constexpr double PI { 3.14159 };  // 编译时常量
  constexpr int array_size { 10 };  // 可用于数组大小定义
  ```
- **使用 `const`**  
  当变量的值在运行时确定或涉及动态类型（如 `std::string`）时：
  ```cpp
  const int user_input { getUserValue() };  // 运行时常量
  const std::string name { "Alice" };       // 不支持 constexpr
  ```

#### 4. **代码示例与错误分析**
```cpp
// 正确示例
constexpr int a { 5 };             // 常量表达式初始化
constexpr int b { a * 2 };         // a 是编译时常量，表达式合法

// 错误示例
int runtime_val = 10;
constexpr int c { runtime_val };   // 错误：runtime_val 不是常量表达式

int getValue() { return 5; }
constexpr int d { getValue() };    // 错误：函数返回值非编译时确定
```

#### 5. **函数参数的限制**
- **函数参数不能为 `constexpr`**  
  函数参数在运行时求值，即使传入编译时常量，参数仍被视为运行时常量：
  ```cpp
  void print(constexpr int value) { ... }  // 错误！函数参数不可用 constexpr
  ```

#### 6. **常量折叠（Constant Folding）**
- **编译器的自动优化**  
  即使表达式在运行时上下文中，编译器会将其中可计算的常量子表达式优化为结果值：
  ```cpp
  int x { 3 + 4 };  // 可能被优化为 int x { 7 };
  ```
- **`constexpr` 明确优化意图**  
  使用 `constexpr` 确保变量参与常量折叠：
  ```cpp
  constexpr int y { 3 + 4 };  // 明确要求编译时计算
  ```

#### 7. **最佳实践**
1. **优先使用 `constexpr`**  
   若变量值在编译时已知且不修改，声明为 `constexpr` 以最大化优化机会。
2. **动态类型使用 `const`**  
   如 `std::string`、`std::vector` 等动态分配的类型只能用 `const`。
3. **避免混淆**  
   `constexpr` 明确表达编译时常量意图，避免依赖编译器的隐式判断。

#### 8. **注意事项**
- **旧代码可能未遵循最佳实践**  
  部分遗留代码可能仍用 `const` 替代 `constexpr`，建议更新。
- **`constexpr` 函数的扩展性**  
  C++支持 `constexpr` 函数（在编译时求值），需结合上下文使用（后续章节详解）。

### 关键总结表
| 概念                | 说明                                                                 |
|---------------------|----------------------------------------------------------------------|
| **`constexpr` 变量** | 必须用常量表达式初始化，确保编译时求值，优化确定性高。               |
| **`const` 变量**     | 可为编译时或运行时常量，初始化灵活性高，优化依赖上下文。             |
| **常量折叠**         | 编译器优化策略，将常量子表达式替换为结果值，即使上下文为运行时。     |
| **函数参数**         | 不可用 `constexpr`，函数内视为运行时常量。                           |

通过 `constexpr` 明确编译时常量意图，帮助编译器优化代码，提升性能。
