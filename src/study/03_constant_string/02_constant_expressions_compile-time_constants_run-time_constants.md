### 常量表达式、编译时常量和运行时常量

#### 1. **常量表达式**
- **定义**：常量表达式是编译器在编译时能够计算的表达式。表达式中的所有值必须在编译时已知，且所有运算符和函数必须支持编译时求值。
- **优化**：编译器可以在编译时计算常量表达式，并用结果替换表达式，从而减少运行时计算的开销。
- **示例**：
  ```cpp
  int x { 3 + 4 };  // 3 + 4 是常量表达式，编译器会将其替换为 7
  ```

#### 2. **编译时常量**
- **定义**：编译时常量是其值为常量表达式的常量。常变量的初始值必须是常量表达式。
- **优化**：编译器可以在编译时替换编译时常量的值，从而避免运行时访问内存。
- **示例**：
  ```cpp
  const int x { 3 };  // x 是编译时常量
  const int y { 4 };  // y 是编译时常量
  const int z { x + y };  // x + y 是常量表达式，z 是编译时常量
  ```

#### 3. **运行时常量**
- **定义**：运行时常量是其初始值在运行时才能确定的常量。即使使用 `const` 关键字，如果初始值在编译时未知，则该常量是运行时常量。
- **用途**：主要用于确保对象的值在运行时不会被修改。
- **示例**：
  ```cpp
  const int y { getNumber() };  // y 是运行时常量，因为 getNumber() 的返回值在运行时才能确定
  const int z { x + y };  // x + y 是运行时常量，z 是运行时常量
  ```

#### 4. **优化机会**
- **常量表达式优化**：编译器可以在编译时计算常量表达式，并用结果替换表达式，从而减少运行时计算的开销。
- **编译时常量优化**：编译器可以在编译时替换编译时常量的值，从而避免运行时访问内存。
- **运行时常量优化**：运行时常量无法在编译时优化，因为它们的值在运行时才能确定。

#### 5. **关键点**
- **常量表达式**：在编译时计算，减少运行时开销。
- **编译时常量**：帮助编译器进行更多优化，通常用于命名常量。
- **运行时常量**：确保对象的值在运行时不会被修改，但无法在编译时优化。

#### 6. **代码示例**
```cpp
#include <iostream>

int getNumber()
{
    std::cout << "Enter a number: ";
    int y{};
    std::cin >> y;
    return y;  
}

int main()
{
    const int x { 3 };           // x 是编译时常量
    const int y { getNumber() };  // y 是运行时常量
    const int z { x + y };        // x + y 是运行时常量, z 是运行时常量

    std::cout << z << '\n'; 
    return 0;
}
```

### 总结
- **常量表达式**和**编译时常量**有助于编译器进行优化，减少运行时开销。
- **运行时常量**用于确保对象的值在运行时不会被修改，但无法在编译时优化。
- 使用 `const` 关键字可以帮助编译器更好地优化代码，尤其是在使用编译时常量时。
