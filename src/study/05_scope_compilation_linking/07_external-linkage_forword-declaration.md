# 外部链接和变量前向声明
## 一、引言
在上一课中，我们了解到内部链接可将标识符的使用范围限制在单个文件内。而在本节课，我们将深入探讨外部链接的概念。

## 二、外部链接概述
具有外部链接的标识符，不仅能在定义它的文件中被访问，还可以通过前向声明在其他代码文件中使用。从这个角度看，具有外部链接的标识符才是真正意义上的“全局”标识符，因为它们能够在程序的任何位置使用。

## 三、默认具有外部链接的函数
在包含多个代码文件的程序里，我们可以从一个文件调用另一个文件中定义的函数，这是因为函数默认具有外部链接属性。

为了调用在其他文件中定义的函数，必须在使用该函数的文件中添加函数的前向声明。前向声明的作用是告知编译器该函数的存在，而链接器则负责将函数调用与实际的函数定义进行连接。

下面是一个具体示例：
- **a.cpp**
```cpp
#include <iostream>

void sayHi() // 该函数具有外部链接，可在其他文件中使用
{
    std::cout << "Hi!\n";
}
```
- **main.cpp**
```cpp
void sayHi(); // 函数 sayHi 的前向声明，使 sayHi 能在本文件中使用

int main()
{
    sayHi(); // 调用其他文件中定义的函数，链接器会完成连接
    return 0;
}
```
上述程序的输出为：
```
Hi!
```
在这个示例中，`main.cpp` 里 `sayHi()` 函数的前向声明，让 `main.cpp` 能够访问 `a.cpp` 中定义的 `sayHi()` 函数。前向声明满足了编译器的要求，链接器则将函数调用与函数定义成功连接。若 `sayHi()` 函数具有内部链接，链接器将无法完成连接，从而导致链接错误。

## 四、具有外部链接的全局变量
具有外部链接的全局变量也被称为外部变量。要将全局变量设置为外部变量（以便能被其他文件访问），可以使用 `extern` 关键字。示例如下：
```cpp
int g_x { 2 }; // 非常量全局变量默认是外部链接

extern const int g_y { 3 }; // const 全局变量使用 extern 设置为外部链接
extern constexpr int g_z { 3 }; // constexpr 全局变量使用 extern 设置为外部链接（但此定义实际无用，后续会说明）

int main()
{
    return 0;
}
```
默认情况下，非常量的全局变量具有外部链接属性，即使添加 `extern` 关键字也会被忽略。

## 五、通过 `extern` 关键字进行变量前向声明
若要使用在其他文件中定义的外部全局变量，必须在希望使用该变量的文件中添加全局变量的前向声明。对于变量，可以通过 `extern` 关键字（且不赋予初始化值）来创建前向声明。

下面是使用变量前向声明的示例：
- **a.cpp**
```cpp
// 全局变量定义
int g_x { 2 }; // 非常量全局变量默认是外部链接
extern const int g_y { 3 }; // const 全局变量使用 extern 设置为外部链接
```
- **main.cpp**
```cpp
#include <iostream>

extern int g_x; // 此处的 extern 表示 g_x 是在其他地方定义的全局变量，这里进行前向声明
extern const int g_y; // 同理，对 const 全局变量 g_y 进行前向声明

int main()
{
    std::cout << g_x << ' ' << g_y << '\n'; // 打印 2 3
    return 0;
}
```
在这个示例中，`a.cpp` 和 `main.cpp` 引用的是同一个名为 `g_x` 的全局变量。所以，即便 `g_x` 是在 `a.cpp` 中定义和初始化的，我们也能通过前向声明在 `main.cpp` 中使用它的值。

需要注意的是，`extern` 关键字在不同上下文中含义不同。在某些情况下，`extern` 表示“为该变量提供外部链接”；在其他情况下，它表示“这是在其他地方定义的外部变量的前向声明”。这可能会造成混淆，后续课程会对其所有用法（包括作用域、存储期和链接）进行总结。

另外，函数前向声明不需要 `extern` 关键字，因为编译器可以根据是否提供函数体来判断是在定义新函数还是进行前向声明。而变量前向声明则需要 `extern` 关键字来区分未初始化的变量定义和变量前向声明（它们在形式上很相似）：
```cpp
// 非常量
int g_x; // 变量定义（可不用显式初始化）
extern int g_x; // 前向声明（无初始化）

// 常量
extern const int g_y { 1 }; // 变量定义（const 外部变量定义需要初始化值）
extern const int g_y; // 前向声明（无初始化）
```

## 六、注意
1. **定义未初始化的非常量全局变量**：如果要定义未初始化的非常量全局变量，不要使用 `extern` 关键字，否则 C++ 会将其视为变量的前向声明。
2. **`constexpr` 变量的前向声明**：尽管可以通过 `extern` 关键字为 `constexpr` 变量提供外部链接，但不能将其前向声明为 `constexpr`。因为编译器需要在编译时知道 `constexpr` 变量的值，如果该值在其他文件中定义，编译器无法获取该值。不过，可以将 `constexpr` 变量前向声明为 `const`，但这种做法实际用处不大。

## 七、快速摘要
```cpp
// 外部全局变量定义:
int g_x;                       // 定义未初始化的外部全局变量（默认初始化为 0）
extern const int g_x{ 1 };     // 定义初始化了的 const 外部全局变量 
extern constexpr int g_x{ 2 }; // 定义初始化了的 constexpr 外部全局变量

// 前向声明
extern int g_y;                // 前向声明非常量全局变量
extern const int g_y;          // 前向声明 const 全局变量
extern constexpr int g_y;      // 不被允许: constexpr 变量不能被前向声明
```
