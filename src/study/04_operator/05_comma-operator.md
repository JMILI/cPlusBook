### 逗号运算符

#### 概述
逗号运算符（`,`）在C++中允许在单个表达式的位置编写多个表达式。它首先计算左操作数，然后计算右操作数，并返回右操作数的结果。

#### 语法
```cpp
x, y
```
- **x** 和 **y** 是两个表达式。
- 逗号运算符会先计算 **x**，然后计算 **y**，最后返回 **y** 的值。

#### 示例代码
```cpp
#include <iostream>

int main() {
    int x{1};
    int y{2};

    std::cout << (++x, ++y) << '\n'; // x 递增到 2，y 递增到 3，返回 y 的值 3
    return 0;
}
```
- **输出**: `3`

#### 优先级
逗号运算符的优先级是所有运算符中最低的，甚至低于赋值运算符。因此，以下两行代码的行为不同：
```cpp
z = (a, b); // 计算 (a, b) 得到 b 的值，然后将 b 赋值给 z
z = a, b;   // 计算 (z = a), b，z 得到 a 的值，然后计算 b，丢弃 b 的结果
```

#### 最佳实践
- **避免使用逗号运算符**，除非在 `for` 循环中。
- 可以将逗号运算符拆分为多个语句以提高代码可读性。

#### 逗号作为分隔符
在C++中，逗号通常用作分隔符，例如在函数参数列表或变量声明中：
```cpp
void foo(int x, int y); // 逗号分隔参数
int a = 1, b = 2;       // 逗号分隔变量声明
```
