# 深入解析 C++ 算术运算符



## 一、运算符分类概览
### 1.1 运算符类型
| 类型         | 运算符数量 | 示例               |
|--------------|------------|--------------------|
| 一元运算符   | 2          | `+x`, `-x`         |
| 二元运算符   | 5          | `x + y`, `x * y`   |
| 赋值运算符   | 6          | `x = y`, `x += y`  |


---

## 二、一元算术运算符详解
### 2.1 基本定义
```cpp
int x = 5;
int y = -x;  // y = -5
int z = +x;  // z = 5
```

### 2.2 使用场景
- **一元减号**：数值取反
- **一元加号**：保持数值不变（主要用于对称性）

### 2.3 注意事项
- 避免与二元运算符混淆
  ```cpp
  int result = 5 - -3; // 第一个减号是二元运算符，第二个是一元运算符
  ```

## 三、二元算术运算符详解
### 3.1 基本运算符
| 运算符 | 符号 | 示例     | 结果       |
|--------|------|----------|------------|
| 加     | `+`  | `5 + 3`  | 8          |
| 减     | `-`  | `5 - 3`  | 2          |
| 乘     | `*`  | `5 * 3`  | 15         |
| 除     | `/`  | `5 / 2`  | 2（整数）  |
| 取余   | `%`  | `5 % 2`  | 1          |

### 3.2 除法类型
#### 整数除法
```cpp
int a = 7 / 4;    // a = 1
int b = -7 / 4;   // b = -1
```

#### 浮点除法
```cpp
double c = 7.0 / 4;  // c = 1.75
double d = 7 / 4.0;  // d = 1.75
```

### 3.3 类型转换
```cpp
int x = 7;
int y = 4;
double result = static_cast<double>(x) / y; // result = 1.75
```

### 3.4 除零问题
| 类型     | 除数 | 结果               |
|----------|------|--------------------|
| 整数除法 | 0    | 未定义行为         |
| 浮点除法 | 0.0  | NaN 或 Inf（IEEE754）|

**示例代码**：
```cpp
#include <iostream>
int main() {
    int x = 12;
    int y = 0;
    // std::cout << x / y; // 未定义行为

    double d = 0.0;
    std::cout << 12.0 / d; // 输出 inf 或 nan
    return 0;
}
```

## 四、算术赋值运算符
### 4.1 基本定义
| 运算符 | 符号 | 示例     | 等价表达式  |
|--------|------|----------|-------------|
| 赋值   | `=`  | `x = y`  | `x = y`     |
| 加赋值 | `+=` | `x += y` | `x = x + y` |
| 减赋值 | `-=` | `x -= y` | `x = x - y` |
| 乘赋值 | `*=` | `x *= y` | `x = x * y` |
| 除赋值 | `/=` | `x /= y` | `x = x / y` |
| 取余赋值 | `%=` | `x %= y` | `x = x % y` |

### 4.2 使用示例
```cpp
int x = 10;
x += 5;  // x = 15
x -= 3;  // x = 12
x *= 2;  // x = 24
x /= 4;  // x = 6
x %= 5;  // x = 1
```

### 4.3 优势分析
- **简洁性**：减少代码冗余
- **可读性**：直观表达操作意图
- **性能**：可能优化为单指令操作

## 五、综合应用案例
### 5.1 计算器实现
```cpp
#include <iostream>
int main() {
    double num1, num2;
    char op;

    std::cout << "Enter two numbers and an operator (+, -, *, /): ";
    std::cin >> num1 >> num2 >> op;

    switch (op) {
        case '+':
            std::cout << "Result: " << num1 + num2;
            break;
        case '-':
            std::cout << "Result: " << num1 - num2;
            break;
        case '*':
            std::cout << "Result: " << num1 * num2;
            break;
        case '/':
            if (num2 != 0.0)
                std::cout << "Result: " << num1 / num2;
            else
                std::cout << "Error: Division by zero";
            break;
        default:
            std::cout << "Invalid operator";
    }
    return 0;
}
```

### 5.2 性能优化示例
```cpp
// 传统方式
int x = 10;
x = x * 2 + 5;

// 优化方式
int x = 10;
x *= 2;
x += 5;
```

## 六、关键知识点总结
### 6.1 运算符优先级表
| 优先级 | 运算符         | 结合性   |
|--------|----------------|----------|
| 1      | `+`（一元）    | 右到左   |
| 1      | `-`（一元）    | 右到左   |
| 2      | `*`, `/`, `%`  | 左到右   |
| 3      | `+`, `-`       | 左到右   |
| 4      | `=`, `+=`, `-=`| 右到左   |

### 6.2 最佳实践
1. **避免除零**：始终检查除数是否为零
2. **类型转换**：使用 `static_cast` 进行显式类型转换
3. **赋值运算符**：优先使用复合赋值运算符以提高代码效率
4. **浮点精度**：注意浮点数运算的精度问题

```cpp
// 示例：安全除法函数
double safeDivide(double numerator, double denominator) {
    if (denominator == 0.0) {
        throw std::runtime_error("Division by zero");
    }
    return numerator / denominator;
}
```
