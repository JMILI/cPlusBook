

### C++ 运算符重载核心知识点总结表

---

#### **一、运算符重载的限制**
| **限制类型**          | **具体限制**                                                                 | **说明**                                                                 |
|-----------------------|----------------------------------------------------------------------------|--------------------------------------------------------------------------|
| **不可重载的运算符**    | `?:`, `sizeof`, `::`, `.`, `.*`, `typeid`, 类型转换运算符 (`const_cast` 等)。 | 这些运算符的语义与底层实现紧密相关，无法重载。                          |
| **操作数要求**          | 至少有一个操作数必须是用户定义的类型（如类或结构体）。                          | 不能重载两个原生类型（如 `int + int`）的运算符。                        |
| **元数与优先级**        | - 不能改变运算符的元数（如二元运算符不能重载为一元）。<br>- 不能修改优先级和结合性。 | 例如 `a + b * c` 仍先计算 `*`，即使 `+` 被重载。                       |
| **标准库类注意事项**    | 尽量避免重载作用于标准库类型的运算符（如 `operator+(double, std::string)`），以防未来标准冲突。 | 可能导致兼容性问题。                                                  |

---

#### **二、运算符重载方法对比**
| **方法类型**       | **适用场景**                                                                 | **优点**                                                                 | **缺点**                                                                 |
|-------------------|----------------------------------------------------------------------------|--------------------------------------------------------------------------|--------------------------------------------------------------------------|
| **成员函数**       | - 赋值运算符 (`=`)、下标 (`[]`)、函数调用 (`()`)、成员选择 (`->`)。<br>- 一元运算符。<br>- 修改左操作数的二元运算符（如 `+=`）。 | 直接访问私有成员，语法自然（隐含 `this`）。                            | 无法处理左操作数为非类类型的场景（如 `5 + myObject`）。               |
| **友元函数**       | - 需要直接访问私有成员但不符合成员函数条件的场景（如左操作数为非类类型）。<br>- 复杂运算符（如流插入 `<<`）。 | 支持更灵活的参数类型，可访问私有成员。                                | 破坏封装性，需显式声明友元关系。                                      |
| **普通函数**       | - 不修改左操作数的二元运算符（如 `+`、`-`）。<br>- 无需访问私有成员的场景。 | 通过公共接口实现，封装性好。                                            | 需类提供公共成员函数（如 `getValue()`），灵活性较低。                    |

---

#### **三、特定运算符重载要点**
| **运算符**          | **注意事项**                                                                 | **示例**                                                                 |
|---------------------|----------------------------------------------------------------------------|--------------------------------------------------------------------------|
| **下标运算符 `[]`**  | - 需同时重载 `const` 和非常量版本：<br>`T& operator[](size_t index)`<br>`const T& operator[](size_t index) const`。<br>- 处理越界问题（可选抛异常或断言）。 | ```cpp<br>class Array {<br>  public:<br>  int& operator[](int idx) { return data[idx]; }<br>  const int& operator[](int idx) const { return data[idx]; }<br>}; ``` |
| **括号运算符 `()`**  | - 主要用于定义函数对象（函子），通过重载 `operator()` 实现函数调用行为。          | ```cpp<br>struct Functor {<br>  void operator()(int x) { /* 逻辑 */ }<br>}; ``` |
| **赋值运算符 `=`**   | - 必须处理自我赋值（`if (this != &other)`）。<br>- 资源管理（深拷贝，避免内存泄漏）。 | ```cpp<br>MyClass& operator=(const MyClass& other) {<br>  if (this != &other) { /* 深拷贝 */ }<br>  return *this;<br>} ``` |

### 总结原则
1. **不可重载的运算符**：
   - 语言内置结构相关（如 `::`, `typeid`, `sizeof`）。
   - 成员访问运算符（`.`, `->`）。
   - 条件运算符 `?:` 和三向比较 `<>`（C++20 的 `<=>` 可重载）。

2. **推荐方法**：
   - **对称性要求**（如 `+`, `-`, `*`）：优先普通函数或友元函数。
   - **修改左操作数**（如 `+=`, `[]`）：必须成员函数。
   - **输入输出**（`<<`, `>>`）：必须友元函数。
   - **类型转换**（`()`）：优先成员函数，避免隐式转换风险。

3. **特殊注意事项**：
   - **自我赋值检查**：必须在 `operator=` 中处理。
   - **短路逻辑**：逻辑运算符 `&&`, `||` 必须用普通函数实现。
   - **封装性**：尽量通过公共接口实现运算符（如用 `getValue()` 支持普通函数重载）。

通过遵循这些原则，可以确保运算符重载的语义一致性、性能优化和代码可维护性。

> 下标运算符（`operator[]`）允许类提供类似数组的访问方式。通过重载此运算符，可以控制对类内部数据的读写，增强封装性和安全性。在重载时加入索引有效性验证，防止越界访问。

```cpp
#include <cassert>
#include <iterator> // for std::size

class SafeArray {
private:
    int m_data[5]{};
public:
    int& operator[](int index) {
        assert(index >= 0 && static_cast<size_t>(index) < std::size(m_data));
        return m_data[index];
    }

    const int& operator[](int index) const {
        assert(index >= 0 && static_cast<size_t>(index) < std::size(m_data));
        return m_data[index];
    }
};
```

>括号运算符 `operator()`


##### 累加器函子

```cpp
#include <iostream>

class Accumulator {
private:
    int m_sum{0};

public:
    int operator()(int value) {
        return m_sum += value; // 累加并返回当前值
    }

    void reset() { m_sum = 0; }
};

int main() {
    Accumulator acc;
    std::cout << acc(10) << "\n"; // 输出 10
    std::cout << acc(20) << "\n"; // 输出 30
    acc.reset();
    std::cout << acc(5) << "\n";  // 输出 5
    return 0;
}
```

> 类型转换运算符重载:成员函数



| **特性**               | **转换构造函数**             | **类型转换运算符**           |
|------------------------|-----------------------------|-----------------------------|
| **转换方向**           | 其他类型 → 当前类            | 当前类 → 其他类型            |
| **定义位置**           | 当前类中                    | 当前类中                    |
| **适用场景**           | 优先使用，语义更清晰         | 无法修改目标类型时使用       |
| **循环依赖处理**       | 可能导致头文件循环引用       | 避免循环依赖（如 `string` 与 `string_view`） |


```cpp
#include <iostream>

class Cents {
private:
    int m_cents;
public:
    Cents(int cents = 0) : m_cents(cents) {}
    
    // 使用 `explicit` 关键字强制显式调用类型转换，防止意外的隐式转换。显式转换为 int
    explicit operator int() const { return m_cents; }
};

class Dollars {
private:
    int m_dollars;
public:
    Dollars(int dollars = 0) : m_dollars(dollars) {}
    
    // 隐式转换为 Cents（允许自然使用）
    operator Cents() const { return Cents(m_dollars * 100); }
};

void printCents(Cents cents) {
    std::cout << static_cast<int>(cents) << " cents\n"; // 必须显式转换
}

int main() {
    Dollars dollars{5};
    printCents(dollars); // 隐式调用 operator Cents()
    
    Cents cents = dollars; // 隐式转换
    int value = static_cast<int>(cents); // 显式转换
    std::cout << value << "\n"; // 输出 500
    return 0;
}
```

> 赋值运算符




#### **1. 拷贝赋值与拷贝构造函数的区别**
| **概念**          | **拷贝构造函数**                          | **拷贝赋值运算符**                          |
|-------------------|-----------------------------------------|-----------------------------------------|
| **触发场景**        | 初始化新对象（如 `a = b` 的初始化）      | 替换已有对象内容（如 `a = b` 的赋值）      |
| **语法形式**        | `Class obj(const Class& other)`           | `Class& operator=(const Class& other)`     |
| **典型用途**        | 对象创建、参数传递、返回值                | 对象赋值、资源更新                        |

---

#### **2. 自我赋值问题与处理**
| **问题场景**        | **错误示例**                                                                 | **正确实现**                                                                 |
|-------------------|-----------------------------------------------------------------------------|-----------------------------------------------------------------------------|
| **动态内存风险**    | 释放原有内存后访问悬空指针：<br>`delete[] m_data; m_data = new ...;`       | 添加自我赋值检查：<br>`if (this == &other) return *this;`                  |
| **基本类型安全**    | 无需检查（如 `int`、`double` 成员）：<br>`m_numerator = other.m_numerator;` | 建议保留检查以提高代码健壮性（防御性编程）                                |



```cpp
MyString& MyString::operator=(const MyString& other) {
    if (this == &other) return *this; // 关键：检查是否为同一对象
    delete[] m_data;
    m_data = new char[strlen(other.m_data) + 1];
    strcpy(m_data, other.m_data);
    return *this;
}
```

| **默认行为**        | **生成条件**                              | **示例**                                                                 |
|-------------------|-----------------------------------------|-------------------------------------------------------------------------|
| 成员级赋值        | 未显式定义时，编译器自动生成              | `Point a = b;` 调用隐式 `operator=`，执行 `a.x = b.x; a.y = b.y;`       |

#### **4. 常量成员对赋值的影响**
| **规则**          | **现象**                                                                 | **解决方案**                                                             |
|-------------------|-------------------------------------------------------------------------|-------------------------------------------------------------------------|
| **隐式删除**        | 含 `const` 成员的类，隐式 `operator=` 被删除：<br>`a = b;`（错误）      | 显式定义 `operator=` 并处理 `const` 成员（需通过 `mutable` 或重构设计） |
| **显式定义限制**    | 无法直接修改 `const` 成员：<br>`id = other.id;`（错误）                | 避免在 `const` 成员存在时重载赋值运算符，或使用 `mutable` 关键字放宽限制 |

---

#### **5. 赋值运算符最佳实践**
| **要点**          | **说明**                                                                 |
|-------------------|-------------------------------------------------------------------------|
| **自我赋值检查**    | 所有涉及资源的重载必须包含 `if (this == &other) return *this;`          |
| **资源管理顺序**    | 释放旧资源 → 分配新资源 → 更新成员变量                                    |
| **返回引用**        | 返回 `*this` 以支持链式赋值（如 `a = b = c;`）                           |
| **深拷贝处理**      | 动态内存类必须深拷贝（避免悬空指针和重复释放）                            |
| **避免隐式赋值**    | 管理资源的类应显式定义 `operator=`，禁用默认行为                          |

### Rule of Three（三法则）

**原则**：若类需要自定义以下任一函数，通常需定义全部三个：
1. **析构函数**：释放动态分配的资源。
2. **拷贝构造函数**：实现深拷贝。
3. **赋值运算符**：安全赋值，处理自我赋值和资源释放。

### 浅拷贝和深拷贝

> 对于基本类型，int，float等都是简单的值复制，也就是复制副本，没有深浅拷贝

> 对于复合类型，类，结构体等，
>
>     浅拷贝：复制指针，多个对象共享同一块内存。有
> 
>     深拷贝：复制指针指向的内存（需手动 new/delete 或智能指针管理）。
> 

>对于复杂类型，例如类，有三种方式进行深拷贝：

1. 自定义拷贝构造函数
2. 自定义赋值运算符
3. 辅助函数 例如：`deepCopy`

### 函数模板和运算符重载


> 在使用函数模板的时候，需要注意，函数类涉及到的所有运算符需要重载，
```cpp
#include <iostream>

class Cents {
private:
    int m_cents;
public:
    Cents(int cents) : m_cents(cents) {}
    
    // 运算符重载
    friend bool operator<(const Cents& c1, const Cents& c2) {
        return c1.m_cents < c2.m_cents;
    }
    
    Cents& operator+=(const Cents& other) {
        m_cents += other.m_cents;
        return *this;
    }
    
    Cents& operator/=(int divisor) {
        m_cents /= divisor;
        return *this;
    }
    
    friend std::ostream& operator<<(std::ostream& os, const Cents& c) {
        os << c.m_cents << " cents";
        return os;
    }
};

template <typename T>
const T& max(const T& a, const T& b) {
    return (a < b) ? b : a;// 需要 T 类型支持 operator<
}

template <typename T>
T average(const T* arr, int size) {
    T sum{0};
    for (int i = 0; i < size; ++i) {
        sum += arr[i];// 需要 T 支持 operator+=
    }
    sum /= size;// 需要 T 支持 operator/=
    return sum;
}

int main() {
    // 使用 max 函数
    Cents nickel{5}, dime{10};
    std::cout << "Max: " << max(nickel, dime) << "\n"; // 输出：Max: 10 cents
    
    // 使用 average 函数
    Cents arr[] = {Cents(5), Cents(15), Cents(10)};
    Cents avg = average(arr, 3);
    std::cout << "Average: " << avg << "\n"; // 输出：Average: 10 cents
    
    return 0;
}
```
