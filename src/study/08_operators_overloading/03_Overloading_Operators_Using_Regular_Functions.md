### C++ 普通函数重载运算符详解

---

#### 一、普通函数重载运算符的核心思想
1. **定义**  
   普通函数重载运算符是指将运算符定义为类外部的非成员函数，通过类的公共接口（如成员函数）间接访问私有数据。

2. **与友元函数的区别**  
   | 特性                | 普通函数                     | 友元函数                     |
   |---------------------|------------------------------|------------------------------|
   | **访问权限**        | 仅能通过公共接口访问成员       | 可直接访问私有成员           |
   | **声明方式**        | 需在头文件显式声明原型       | 可通过类内 `friend` 声明     |
   | **代码耦合度**      | 低（不依赖类内部实现细节）     | 高（需提前暴露私有成员）     |

---

#### 二、普通函数重载的实现步骤
**示例：`Cents` 类加法重载**
```cpp
// Cents.h
class Cents {
private:
    int m_cents{};

public:
    explicit Cents(int cents) : m_cents{cents} {}
    int getCents() const { return m_cents; }
};

// 函数原型声明
Cents operator+(const Cents& c1, const Cents& c2);
```

```cpp
// Cents.cpp
#include "Cents.h"

Cents operator+(const Cents& c1, const Cents& c2) {
    return Cents{c1.getCents() + c2.getCents()};
}
```

**使用示例**
```cpp
#include "Cents.h"
#include <iostream>

int main() {
    Cents cents1{6}, cents2{8};
    Cents sum = cents1 + cents2;
    std::cout << sum.getCents() << std::endl; // 输出 14
    return 0;
}
```

---

#### 三、普通函数 vs 友元函数的选择
| 场景                  | 推荐方案               | 原因                               |
|-----------------------|------------------------|------------------------------------|
| **无需访问私有成员**  | 普通函数               | 通过公共接口实现，降低耦合度       |
| **需要高效访问私有数据**| 友元函数               | 避免重复调用公共接口的开销         |
| **运算符逻辑复杂**      | 成员函数或友元函数     | 可直接操作对象状态                 |

---

#### 四、分离编译与头文件管理
**关键要点**
1. **头文件声明**：必须在头文件中声明运算符函数原型，否则其他文件无法链接。
2. **源文件定义**：函数定义放在源文件中，避免重复定义错误。
3. **包含关系**：使用 `#include` 引入头文件，确保编译器可见性。

**示例：多文件项目结构**
```
├── Cents.h              // 类定义与函数原型声明
├── Cents.cpp            // 成员函数与运算符定义
└── main.cpp             // 主程序入口
```

---

#### 五、普通函数的局限性
1. **性能开销**  
   每次访问私有成员需通过公共接口（如 `getCents()`），可能引入额外函数调用开销。

2. **功能限制**  
   若类未提供必要的公共接口（如 `getCents()`），普通函数无法实现所需功能。

---

#### 六、最佳实践指南
1. **优先使用普通函数**
    - 当运算符逻辑不依赖私有成员时（如算术运算符）。
    - 避免不必要的友元声明，减少代码耦合。

2. **合理设计公共接口**
    - 提供简洁的成员函数（如 `getCents()`），以支持普通函数重载。
    - 避免过度暴露内部数据（如直接返回 `m_cents`）。

3. **分离编译注意事项**
    - 确保头文件中的函数原型与源文件定义一致。
    - 使用 `inline` 或 `constexpr` 优化简单运算符函数。

---

#### 七、总结
普通函数重载运算符通过公共接口间接访问类的私有数据，具有低耦合度和高封装性的优点。适用于以下场景：
- 算术运算符重载（如 `+`、`-`）。
- 不需要修改对象状态的运算符（如比较运算符 `==`）。
- 需要跨类操作的运算符（如流插入运算符 `<<`）。

通过合理设计公共接口和遵循分离编译规范，普通函数重载能够有效提升代码的可维护性和可扩展性。
